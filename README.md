# Workers-Proxy


## まだアルファ版のツールです。動作の保証はできません。

npx wrangler deploy
または
https://workers.cloudflare.com/playground
からデプロイするだけで使えるようになるWorkersのみで動作するプロキシです。
Xも一応ログインはできます、ブックマーク等一分動作が不安定です、これから修正します。
またI-Filterに関してですが、自動ブロックの対象で、すぐに利用できなくなる場合があります。

## 使い方
HTMLをスクロールして最後の部分の&copy;を3回クリックするとURL入力欄等が出ます。
直リンクで設定画面は
*.workers.dev/i/fj/setting-page
です。
